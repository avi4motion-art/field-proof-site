Common questions

I don't see the Setup tab

Setup is shown to account admins and to anyone on a board that hasn't been set up yet.

A report is stuck in the Outbox

It will be sent automatically when the phone is online. If it shows Failed, tap Retry. If a column was deleted, the report is still created and the answers are kept in the item update.

Where is the PDF?

In the files column of the item created by the report, next to the photos and signature.
